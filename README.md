# KOLABORASI PENGEMBANGAN PERANGKAT LUNAK MENGGUNAKAN GIT DAN GITHUB
Studi Kasus: Aplikasi Catatan Tugas Mahasiswa
#A. Tujuan Praktikum
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
1.	Memahami konsep Version Control System (VCS).
2.	Menggunakan Git untuk mengelola perubahan kode program.
3.	Membuat dan mengelola branch.
4.	Melakukan kolaborasi pengembangan perangkat lunak melalui GitHub.
5.	Membuat dan mengelola Pull Request.
6.	Melakukan Code Review.
7.	Mengidentifikasi dan menyelesaikan Merge Conflict.
8.	Menerapkan workflow pengembangan perangkat lunak secara berkelompok.
#B. Perangkat yang Dibutuhkan
No.	Perangkat	Keterangan
1	Windows 10/11	Sistem operasi
2	Git	Version Control
3	GitHub	Repository online
4	Visual Studio Code	Editor kode
5	CMD	Terminal perintah
6	Browser	Mengakses GitHub
#C. Studi Kasus
Mahasiswa akan mengembangkan aplikasi sederhana bernama Aplikasi Catatan Tugas Mahasiswa.
Aplikasi ini memiliki tiga fitur utama:
•	Login: autentikasi pengguna.
•	Dashboard: menampilkan halaman utama.
•	Catatan Tugas: mengelola daftar tugas mahasiswa.
Proyek dikerjakan oleh tiga mahasiswa dengan pembagian pekerjaan sebagai berikut.
#Anggota	Tanggung Jawab	Branch
Mahasiswa 1	Fitur Login	feature/login
Mahasiswa 2	Fitur Dashboard	feature/dashboard
Mahasiswa 3	Fitur Catatan Tugas	feature/catatan-tugas
